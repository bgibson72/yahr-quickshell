Everything you need, out of the box

Curated defaults, powerful customization, and a unified theme system that syncs across every application.

13 Beautiful Themes

Catppuccin, Dracula, Gruvbox, Nord, TokyoNight, and 8 more. Switch instantly with SuperT — all apps sync in 30–45 seconds.

Frosted panels, specular highlights, accent borders at 35% alpha, and 150ms smooth transitions on every hover and state change.

One-Command Install

Clone the repo and run ./install.sh. The installer handles GPU drivers, AUR, the full graphics stack, and all desktop components.

🎯

GPU-Aware Installation

Auto-detects NVIDIA (dkms/nouveau), AMD, Intel, and Hybrid GPU configs and installs the correct driver stack with proper env vars.

YOLO Unattended Mode

Zero prompts, fully automated. Ideal for scripted installs, VMs, or when you just want the defaults applied with no questions asked.

Rounding, border thickness, workspace style, font, and bar size all survive theme switches. Settings stored in a clean JSON file.

🚀 Installation

From minimal Arch to full desktop

All you need is a minimal Arch Linux installation, an internet connection, and git. The installer does everything else.

  • 1Prerequisites
  • 2Clone the Repo
  • 3Run Installer
  • 4Choose Mode
  • 5Full vs. Minimal
  • 6All Done!
1

Prerequisites

Required

Start from a minimal Arch Linux installation (base system is all you need). The installer detects and handles everything else automatically.

bash — prerequisites
# Make sure git is installed — that's the only hard requirement
[user@arch ~]$ sudo pacman -S git
# Verify your Arch base is up to date
[user@arch ~]$ sudo pacman -Syu

Minimum requirements: Fresh or existing Arch Linux install · Internet connection · git

2

Clone the Repository

Required

Clone YahrShell from GitHub and enter the project directory.

bash — clone
[user@arch ~]$ git clone https://github.com/bgibson72/yahr-quickshell.git
Cloning into 'yahr-quickshell'...
remote: Enumerating objects: done.
[user@arch ~]$ cd yahr-quickshell
3

Run the Installer

Required

The installer script handles everything: GPU driver detection, AUR helper installation, complete graphics stack (Wayland, Mesa, Vulkan, Qt5/Qt6), all desktop components, and your configurations.

bash — install.sh
[user@arch yahr-quickshell]$ ./install.sh

4

Choose Your Install Mode

Choose One

The installer offers two modes. Normal is recommended for first-time users who want control over their choices.

🎛️ Normal Mode Recommended

Interactive prompts let you make every decision.

  • Choose AUR helper (yay / paru)
  • Select NVIDIA driver type
  • Pick optional apps (Neovim, Vesktop, Firefox…)
  • Choose whether to install SDDM

⚡ YOLO Mode

Fully automated, zero prompts.

  • Auto-installs yay as AUR helper
  • Selects proprietary NVIDIA drivers
  • Skips all optional components
  • Perfect for scripts and VM installs
bash — YOLO mode
# Unattended one-liner
[user@arch yahr-quickshell]$ ./install.sh --yolo
5

Full vs. Minimal Install

Choose One

In Normal mode you'll also choose between a Full install (all core components + optional applications) or a Minimal install (core desktop only).

🎯 Full Install

  • Quickshell + Hyprland
  • Kitty + Mako + Wofi
  • PipeWire audio stack
  • Thunar file manager
  • Firefox browser
  • SDDM display manager
  • All GPU drivers
  • Papirus icons + fonts
  • Neovim, Vesktop, VSCodium

🪶 Minimal Install

  • Quickshell + Hyprland
  • Kitty terminal
  • Mako notifications
  • GPU drivers (auto)
  • Core fonts
  • No optional apps
6

Reboot & Enjoy!

Final Step

After the installer completes, reboot to apply GPU driver changes, then log in and launch Hyprland. YahrShell starts automatically.

bash — reboot
✓ Installation complete!
[user@arch yahr-quickshell]$ sudo reboot
# After reboot, log in and start Hyprland:
[user@arch ~]$ Hyprland

🔧 Troubleshooting

Common issues & fixes

Solutions to the most frequently encountered problems. If your issue isn't here, open a GitHub ticket.

Common Quickshell won't start / shows a blank screen
▾

The best way to diagnose is to launch Quickshell from a terminal so you can see the full error output.

  • Run quickshell directly in a terminal and read the error message carefully.
  • Verify it's installed: which quickshell (should return a path like /usr/bin/quickshell).
  • Try replacing the running instance: quickshell --replace &
  • Check the Quickshell config directory exists: ls ~/.config/quickshell/
  • If Hyprland-related, ensure WAYLAND_DISPLAY and HYPRLAND_INSTANCE_SIGNATURE are set.
Common A package is missing / install.sh failed partway through
▾

Install failures are usually caused by a temporary network issue, a changed AUR package URL, or a pacman database lock.

  • Remove any pacman lock: sudo rm /var/lib/pacman/db.lck
  • Update the package database: sudo pacman -Sy
  • Re-run the installer — it is mostly idempotent and skips already-installed packages.
  • For a specific missing package: sudo pacman -S <package> or yay -S <aur-package>
  • If mirrors are slow, refresh: sudo reflector --latest 10 --save /etc/pacman.d/mirrorlist
GPU NVIDIA: black screen, graphical glitches, or Wayland won't start
▾

NVIDIA on Wayland requires specific kernel parameters and module configuration. The installer sets these up automatically, but here's what to check if something's off.

  • Verify drivers: nvidia-smi should show your GPU. If not, the driver isn't loaded.
  • Check /etc/mkinitcpio.conf — MODULES should include nvidia nvidia_modeset nvidia_uvm nvidia_drm.
  • Rebuild initramfs: sudo mkinitcpio -P then reboot.
  • Check kernel parameters: cat /proc/cmdline — look for nvidia-drm.modeset=1.
  • Check LIBVA_DRIVER_NAME, GBM_BACKEND, and __GLX_VENDOR_LIBRARY_NAME env vars in hypr/variables.conf.
Theme Theme switch didn't apply / colors look wrong after switching
▾

Some applications need a restart to pick up new theme colors. Others sync live.

  • Wait 30–45 seconds — some syncs (GTK, Kitty, Hyprlock) happen sequentially in the background.
  • Kitty and Thunar require a restart to apply new colors.
  • Check ~/.config/hypr/.current-theme to see what theme is active.
  • Inspect ~/.config/quickshell/settings.json — the theme field should match.
  • Re-run the theme sync manually: ~/.config/quickshell/switch-theme.sh Catppuccin
  • Restart Quickshell: quickshell --replace &
SDDM SDDM login screen isn't updating with the theme
▾

SDDM sync requires a sudoers rule created during installation. If you skipped SDDM installation, this rule won't exist.

  • Check the sudoers rule exists: sudo cat /etc/sudoers.d/sddm-sync-yahr
  • Manually trigger sync: ~/.config/quickshell/sync-sddm-theme.sh
  • Test the SDDM theme without logging out: sddm-greeter-qt6 --test-mode --theme /usr/share/sddm/themes/yahr-theme
  • Ensure /usr/share/sddm/themes/yahr-theme/ exists and is owned correctly.
Wallpaper Wallpaper shows as black / won't load after reboot
▾

YahrShell uses awww (not swww) as the wallpaper daemon. Make sure it's installed and that the last wallpaper path is valid.

  • Check awww is installed: which awww
  • Check the saved wallpaper path: cat ~/.config/quickshell/last-wallpaper
  • Verify the file exists at that path.
  • Start the daemon manually: awww-daemon & then awww img <path>
  • The daemon is auto-started via hypr/autostart.conf — check that file if it's not starting on login.
Audio No sound / audio devices not showing up
▾

Audio is handled by PipeWire + WirePlumber. Check if the user services are running.

  • Check status: systemctl --user status pipewire pipewire-pulse wireplumber
  • Start if not running: systemctl --user start pipewire pipewire-pulse wireplumber
  • Enable on login: systemctl --user enable pipewire pipewire-pulse wireplumber
  • Open Pavucontrol (pavucontrol) to verify devices are listed.
  • Check wpctl status for WirePlumber device enumeration.
General GTK apps (Thunar, Firefox) are using the wrong or light theme
▾

GTK theme sync uses gsettings and settings.ini. Apps need to be restarted to pick up changes.

  • Run GTK sync manually: ~/.config/quickshell/sync-gtk-theme.sh
  • Verify active GTK theme: gsettings get org.gnome.desktop.interface gtk-theme
  • Use nwg-look to apply and test GTK themes interactively.
  • Restart Thunar fully: thunar -q && thunar &
  • Firefox uses userChrome.css — sync via ~/.config/quickshell/sync-firefox-theme.sh

🐛 Still stuck? Open a GitHub Issue

The YahrShell community is happy to help. When filing an issue, please include the following so we can diagnose quickly:

Your GPU model and driver version
Arch Linux / kernel version (uname -r)
The exact error message or output
Steps to reproduce the problem
Contents of relevant config files
Quickshell / Hyprland version (quickshell --version)
Whether you used YOLO or Normal install mode
Screenshot or screen recording if visual
